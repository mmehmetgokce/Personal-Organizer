# Personal Organizer

This project is a desktop application developed to digitize personal data management, task tracking, and daily planning processes. The project prioritizes object-oriented programming (OOP) principles and user-friendly interface design.


## Project Objectives

* To enable users to organize their daily tasks, appointments, and notes through a single platform.
* To provide practical solutions for data management and file system (I/O) issues.


## Technologies and Features Used

* **C# & .NET:** The application's core programming language and framework.
* **Windows Forms (WinForms):** Graphical user interface (GUI) design.
* **OOP Principles:** Modular code structure is provided using class structures, inheritance, and encapsulation.
* **Data Management:** File processing (File I/O) techniques are applied for the permanent storage of data.
